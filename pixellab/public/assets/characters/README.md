# 캐릭터 스프라이트 에셋

연구실에 출근하는 캐릭터의 픽셀 아트 이미지를 보관하는 폴더입니다.
**닉네임(한글)으로 출근하면, 등록된 캐릭터의 스프라이트가 등장**합니다.
등록되지 않은 닉네임은 기존 도형(programmatic) 캐릭터로 표시됩니다.

## 폴더 / 파일 규칙 (모두 영어 소문자)

```
assets/characters/
├── <key>/              ← 캐릭터별 폴더 (영어 key)
│   ├── normal.png      ← 필수: 기본/작업중 얼굴
│   ├── happy.png       ← 선택: 출근 직후 환영 (2.5초)
│   ├── cry.png         ← 선택: 자리비움(away)
│   └── angry.png       ← 선택: 회의중(meeting)·실험중(experiment)
└── ...                 ← 캐릭터는 최대 9명까지
```

- 보유하지 않은 표정은 자동으로 `normal.png`로 폴백됩니다.
- `normal.png`가 없으면 그 캐릭터는 도형 캐릭터로 표시됩니다.

## 표정 ↔ 상태 매핑

| 상태 | 사용 이미지 |
|------|-------------|
| 출근 직후 (2.5초) | `happy` |
| 작업중 (기본) | `normal` |
| 자리비움 | `cry` |
| 회의중 / 실험중 | `angry` |

## 이미지 권장 사양

- **투명 배경 PNG** (흰 배경이면 연구실 위에 흰 네모로 보입니다 — 배경 제거 필수)
- 정사각형(예: 1024×1024) 권장. 캐릭터가 프레임을 꽉 채우도록 **여백을 일정하게** 잘라주세요.
  (여백이 표정마다 다르면 크기가 들쑥날쑥해 보입니다.)
- 화면에는 약 122px 높이로 표시됩니다(`SPRITE_TARGET_H`, `game.js`에서 조절 가능).

## 새 캐릭터 등록 방법

1. `assets/characters/<key>/` 폴더를 만들고 위 파일들을 넣습니다.
2. `game.js`의 `CHARACTERS` 레지스트리에 한 줄 추가합니다.

```js
const CHARACTERS = {
  '이은빈': { key: 'eunbin', expressions: ['normal', 'happy', 'cry'] },
  '홍길동': { key: 'gildong', expressions: ['normal', 'happy', 'cry', 'angry'] },
  // ... 최대 9명
};
```

## 현재 등록된 캐릭터

| 닉네임 | key | 보유 표정 | 상태 |
|--------|-----|-----------|------|
| 이은빈 | `eunbin` | normal, happy, cry | 이미지 파일 추가 대기 |
